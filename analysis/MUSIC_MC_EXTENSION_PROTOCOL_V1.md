# Conditional reference-sampling extension v1

2026-09-18. This follow-up is specified after the original three-draw results, alternative grouping and mechanism diagnostics, and after inspecting the original arrangement-level contrast distribution. It is exploratory and not publicly preregistered. Freeze this protocol and new selections before any new fitting. Preserve all original endpoints, inputs and outputs.

## Question and fixed design

Estimate conditional reference-cell sampling variability of the original external endpoint, holding the source inventory, 14 eligible donors, original donor ring and its four triples per held-out donor, six author-annotated types, all 840 original synthetic targets, target compositions/cells, 30,172 genes and official MuSiC settings fixed. This does not estimate uncertainty over donor populations, reference groupings, new targets, source annotations, tissues or measured bulk RNA-seq.

Use budgets 60 and 300 cells per type. Within each triple, compare balanced allocation (20:20:20 and 100:100:100) with 10:1:1 allocation (50:5:5 and 250:25:25), rotating all three dominant donors. The dominant donor is shared across all six types within a reference. No new middle budget or allocation, reference grouping, target composition or software method is introduced.

Generate exactly 12 additional global reference blocks, labelled 3 through 14. Blocks 0 through 2 remain the original saved draws. For donor d, source author-type a and block b, use the original key `music-external-v1|reference|{d}|{a}|{b}`: SHA256 UTF-8 digest first 16 bytes, unsigned big-endian integer, then NumPy PCG64. Permute the complete eligible donor/type row inventory and retain the first 250 rows. Use prefixes for all quotas. Reuse each donor/type/block prefix across reference triples and held-out folds; retain nesting across budgets within an allocation. Allow cells to recur between independently generated blocks; this is conditional random sampling from a fixed finite inventory, not independent biological replication. Do not search seeds or exclude draws based on predictions.

The eligible inventory contains 114,524 cells. The old processed matrix contains only 93,892 selected cells and must not serve as the sampling population. Select from the complete frozen metadata inventory. Supplement old raw counts with required missing-cell counts from the same fixed CELLxGENE H5AD object `c55dc602-d168-4d15-acc1-5de4f2f5d551`; preserve source identity, genes and count units. Do not replace old target cells or sum new targets. Reuse old cells/targets and verified counts where possible, without silently treating an incomplete union as complete source truth.

Each new block has 112 unique reference matrices, 448 held-out logical configurations, 26,880 weighted fits and 53,760 prediction rows including ordinary NNLS. The complete extension has 1,344 references, 5,376 logical configurations, 322,560 weighted fits and 645,120 prediction rows. Each of the original 14 unique triples has 96 references and serves four held-out donors, giving 240 fixed targets per reference.

## Estimands and Monte Carlo precision

For each complete global block, compute MAE in percentage points from the six predicted-minus-true cell proportions, average equally over 60 targets, pair every unequal allocation with the same budget/triple/block/held-out balanced baseline, and then average equally over the three dominant choices, four triples and 14 held-out donors. Define I_b(B) as the resulting 10:1:1-minus-balanced signed accuracy contrast and C_b=I_b(300)-I_b(60). This preserves the original endpoint and pairing; negative C is not proof of a smaller absolute perturbation or lower absolute error.

Report the new 12-block means for weighted I(60), I(300) and C, together with conditional Monte Carlo standard errors `SD(block estimate, ddof=1)/sqrt(12)`. The independent randomization unit for this calculation is a whole global block, not a target, donor, triple, dominant choice or prediction row. Within-block dependence is retained in the block aggregate. The fixed finite cell inventory and fixed targets are conditioned upon. No population P values or population confidence intervals will be calculated.

The prespecified numerical precision target is MCSE <=0.05 percentage points for each of the three weighted quantities. This is an absolute computational precision target, not a biological relevance threshold or a criterion for the sign of the effect. Finish all 12 blocks regardless of intermediate estimates; do not stop early when a direction agrees, a mean crosses zero or an estimated precision target is reached. If any target is missed, report it explicitly; no additional outcome-selected seeds are part of this protocol. Running means/MCSE at block counts 3, 6, 9 and 12 are descriptive diagnostics, not stopping rules or proof of convergence.

Report the original three blocks, new 12 blocks and combined 15 blocks separately. The combined summary is a follow-up estimate, not a replacement disguised as the original prespecified analysis. Report all donor/block values and the same secondary ordinary-NNLS summaries, absolute MAE/RMSE, arrangement signed contrasts, their absolute magnitudes, quantiles and positive/negative counts. Do not introduce a simple donor-level bootstrap, signed-rank or significance test. Precision estimates from the original three blocks are themselves imprecise.

For arrangement distributions, first average paired signed MAE differences over the fixed targets and the specified set of blocks within held-out donor/triple/dominant arrangement. Then summarize the 168 arrangement values at each budget/method. Mean absolute arrangement contrast means mean of absolute values AFTER this within-arrangement averaging; it is not mean target-level absolute error change or prediction-vector distance. Retain each arrangement and donor identifier. Use linearly interpolated empirical quantiles (NumPy/pandas default linear rule) and a 1e-10 percentage-point tolerance for sign/tie counts. The original three-budget arrangement summary and its alternative-grouping counterpart are descriptive additions from already saved results and are not new fitting outcomes.
